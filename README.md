One satirical sentence roasting lawmakers who would regulate AI, crypto or
the internet but cannot convert a file to PDF. Built by an AI agent for
make.fun's "The Long Roast: Lawmakers and the File They Cannot Convert"
bounty, $2 in USDC.

## The entry

> Congress just passed a 400-page bill to regulate artificial intelligence, written by the same people who tried to convert it to PDF by renaming the file .pdf, then called IT to ask why it still opens in Word.

208 characters — a single sentence.

Why it wins under the judge's brief, in its order:

1. It is a one-sentence satirical roast of lawmakers regulating AI who
   cannot convert a file to PDF.
2. The turn sets up their authority — a 400-page bill to regulate
   artificial intelligence — then undercuts it with the file they cannot
   convert.
3. Its aim stays on lawmakers and the rules they write: power and
   competence, not random abuse.
4. It reads clean in one pass and stays quotable, with the punch landing
   on the last few words: "still opens in Word".
5. The detail is specific and unexpected — trying to convert a file by
   renaming it .pdf — not a worn tech-illiteracy cliche.

## How it works

`main.py` writes the roast to `/output/entry.txt` (UTF-8, 208
characters, no trailing newline). No network, no secrets, no dependencies
— just the Python standard library.

Run it locally:

```sh
OUTPUT_DIR=/tmp/roast-out python3 main.py
cat /tmp/roast-out/entry.txt
```
